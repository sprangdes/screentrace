# R4：介面改善 — UI1–UI4 驗收紀錄

日期：2026-10-04。UI1 已驗收，UI2／UI4 完成；UI3 已對應元件的呈現完成，未對應 tag-body 名稱因 OQ-015 待決定而暫停。UI5 未開始。下方保留各輪驗證紀錄。

## 範圍與結果

- 原生 TypeScript 外殼、內嵌 SVG sprite、CSS 設計變數、系統字型、深青主色；文字／背景與語意色通過 AA 4.5:1 測試，焦點環與 reduced-motion 基礎樣式已加入。
- 56px 頂部列放畫面／API、確認模式 switch、匯出 md、匯入與分析資訊。左側為搜尋、清除、地圖／檔案結構、可收合清單、選取高亮；搜尋固定，清單獨立捲動。

- 診斷與元件庫整份移至右側分析資訊 dialog，原中文分組、英文代碼、來源行號、覆寫 orphan、摘要與雜湊仍可到達。右欄未選取時顯示引導與三個快捷提示；選取後空狀態消失。
- 只改 viewer 呈現與文件；分析器、schema、共用 review／md／API 推導模組沒有改動。REQUIREMENTS、既有 fixture／golden 不變。

### 總覽

1440：十張卡初始都在畫布內，縮放工具獨立右下，左上全站導覽預設未勾選；箭頭與行列走廊可看出方向。線與卡片 hover 高亮可區分端點，灰線仍有若干平行重疊，格狀位置沒有依流程深度重排（文件允許的階段選項）。1024：沒有整頁水平捲動，十張卡均可看到，但適合視窗後名稱偏小，實際找畫面更適合用左側清單或放大；UI5 的右欄覆蓋抽屜可讓主畫布更寬。這兩處仍不滿意，沒有把格狀聲稱為方向分層。

### 聚焦

1440：Owner Details 初始在中央，示意徽章貼於預覽右上，黃色橫幅消失；麵包屑與返回圖示不再佔一整列。關聯有箭頭、hover tooltip 保留 URL／縮圖，右欄四個分頁可實際切到資料與技術明細。1024：中央 280×280 預覽完整可見，目的卡仍需在聚焦圖內橫向捲動，沒有擠出整頁；預覽本身為短窗，長頁內容仍須在 iframe 裡捲動，尚不夠寬敞。URL 各處保留 `{ownerId}`。

### 確認模式

1440：標題旁可直接保留／移除／未確認，右欄操作列直接勾／叉／問號；實際把 Owner Details 設 KEEP、首個按鈕設 REMOVE，畫面統計變為保留 1／未確認 9，按鈕移除 1／未確認 67。卡片與清單沒有重複文字徽章；色條和圖示提供回饋。1024：元件三態仍可點，批次按鈕會換行，操作列比較長，需捲動；不能宣稱小螢幕最終版完成。兩尺寸均實際下載 md、清除 localStorage、匯入並再次下載，除產生時間外完全相同。

### API 頁

### UI3 真實驗收發現的缺口（OQ-015）

已精確對應的預覽元件可用可見文字，但 Home／Find owners 的 tag-body 元素沒有 graphComponentId／候選，capture 又把 title 變為 `Title`；圖內共用展開證據不能證明一對一映射。因此 PetClinic 右欄這批導覽仍使用 `home page`／`find owners`，不把此項聲稱完成。已依 §0.3 寫入 [OQ-015](../OPEN_QUESTIONS.md)，暫停該名稱補強並詢問是否另授權最小來源對應補強。沒有採文字相似度、DOM 順序或硬編碼猜配；R4 的分析範圍未擴大。
