# R4：介面改善 — UI1 驗收報告

日期：2026-10-04。UI1 完成，停止等待需求方外觀驗收；UI2–UI5 未開始。

## 範圍與結果

- 原生 TypeScript 外殼、內嵌 SVG sprite、CSS 設計變數、系統字型、深青主色；文字／背景與語意色通過 AA 4.5:1 測試，焦點環與 reduced-motion 基礎樣式已加入。
- 56px 頂部列放畫面／API、確認模式 switch、匯出 md、匯入與分析資訊。左側為搜尋、清除、地圖／檔案結構、可收合清單、選取高亮；搜尋固定，清單獨立捲動。
- 確認模式顯示四種狀態晶片與原畫面／按鈕統計及比例條。原「隨畫面移除」篩選移到統計按鈕、檔案樹決策仍可操作；沒有刪除舊功能。
- 診斷與元件庫整份移至右側分析資訊 dialog，原中文分組、英文代碼、來源行號、覆寫 orphan、摘要與雜湊仍可到達。右欄未選取時顯示引導與三個快捷提示；選取後空狀態消失。
- 只改 viewer 呈現與文件；分析器、schema、共用 review／md／API 推導模組沒有改動。REQUIREMENTS、既有 fixture／golden 不變。

## 既有斷言與舊版反證

逐處對照見 [ADR 0040](../adr/0040-viewer-redesign-assertions.md)：主要導覽從 nav 改 topbar，總覽控制項改地圖；診斷／元件庫定位改資訊抽屜，診斷無溢出檢查移到實際承載抽屜。資料內容、來源、候選、安全、保存及往返斷言原文保留。篩選操作改為狀態晶片，原零卡片結果不變。

- 更新的既有結構定位在舊 R3 HTML 上：6 項／3 失敗、3 通過；失敗為新頂部／抽屜不存在。
- 最終新增五項外殼 E2E 在保留的舊 R3 HTML 上：5 項全失敗；缺頂部與資訊抽屜、搜尋快捷鍵、繼承篩選的新入口。暫存測試僅縮短等待時間，所有新斷言未改。
- 新版五項全部通過；新增 1 unit 驗證 AA 及 reduced-motion，新增 5 E2E 驗證外殼分區、完整診斷／庫內容、安全、快捷鍵、四種寬度及原功能入口。

- **總覽：**1440 寬的頂部控制項有主次，搜尋與左側名稱／URL 清單可直接找到畫面，右側有引導。1024 頂部仍單行，專案名省略但 hover 可讀；卡片因中央寬度較少而縮小，名稱不夠大，UI2／UI5 待改善。資訊抽屜顯示 52 項／6 類診斷與完整元件庫區塊。
- **聚焦：**兩種尺寸選取 Owner Details 後左側高亮且右欄空狀態消失。1440 的右側目的卡需橫向查看，1024 中央預覽更容易被裁到內容容器之外（可捲動，未造成整頁水平捲動）；黃色提示與孤立返回按鈕仍在，屬 UI2。右欄重複確認與查看內容、冒號形式 URL 尚待 UI3，不宣稱已完成。
- **確認模式：**頂部 switch 可開啟，左側立即顯示全部 10／未確認 10／保留 0／移除 0，按鈕未確認 68，狀態比例條與原統計一致。1024 清單獨立捲動，搜尋／篩選留在上方；單筆審查 select 仍保留，三段決策與緊湊按鈕待 UI2／UI3。
- **API 頁：**19 列與原呼叫來源、契約皆仍可操作，頂部 API 選取狀態清楚。1440、1024 方法／狀態仍可能換行，處理器路徑佔寬、右側初始仍是引導；主從清單與徽章屬 UI4，尚未實作。

合成 Spring MVC fixture 已重拍指南的外殼、資訊抽屜、預覽、元件庫覆寫圖片；沒有提交真實專案截圖。使用位置已更新 USER_GUIDE。

- 四類合成專案圖／HTML／md 決定性與審查／覆寫還原通過；PetClinic 固定輸出根重跑 application-graph.json、preview-model.json、viewer-documents.json、HTML 四檔逐 byte 相同。其 canonical graph 與 R3 逐 byte 相同。
- PetClinic 465 份來源 SHA-256 與改版前完全相同；graph／HTML 沒有使用者家目錄字串。報表資料與程式不載入外部資源，預覽安全策略保持。
- 四種外殼寬度 1440／1024／768／390 的總覽、聚焦、API 新測試無整頁水平溢出；最終響應式右側抽屜、單行方法徽章、完整 Tab 順序及 UI2–UI5 規格尚未驗收。
- 追加 Chromium＋WebKit 套件（ST_BROWSERS=chromium,webkit）：63 項全通過，包含 md 往返及元件庫還原；新 UI1 外殼測試本身仍以 Chromium 跑，未宣稱三引擎外殼人工驗收。
- 額外三引擎嘗試未全通過：本機 Firefox 在報表載入前 launch timeout，日誌包含 sandbox_extension_issue_file_to_process／RenderCompositorSWGL；空白頁 smoke 同樣在 launch 8 秒超時。已停止該額外測試，不把 Firefox 或三引擎寫成完成。
- 未驗證：Firefox UI1、真正 Safari／Edge 手動操作、真實業務執行與跨環境預覽位元組相同。未推送／未驗證遠端 CI。
