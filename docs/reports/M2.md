## 3. 測試：數量、指令、結果與失敗項

M2 新增 98 個 Java 測試：WP3 32、WP4 15、WP5 51；由 M1 的 100 個成為 **198 個**，全部通過，0 failure／error／skip。WP4 新增 40 JS 測試；WP5 不新增 JS 相依或測試。

- `mvn -q clean verify`：198 個 Java 全綠。
- `npm --prefix screentrace-js test`：40 個全綠，含 eval／obj[x]／使用者字串對抗性、循環／深度與副作用探針。
- `node --test` 四檔 docs-baseline／safe-files／spring-resource-mappings／capture-static-jsp.security：14 個全綠，需求第 1／2 節原文一致。Chromium 首次因 macOS MachPort sandbox 權限而 1 failure；相同測試取得啟動權限後全綠，JS 關閉，只渲染工具靜態化 HTML。
- 兩個 Node 模組的 `npm audit --audit-level=high`：0 vulnerabilities；最終遠端 npm audit 與 Dependency-Check success。
- `git diff --check` 通過；所有既有 fixture／斷言均保留，schema 字串也未修改。新增／追加測試不算修改舊斷言。

先失敗證據：WP3 URL 例外、標籤來源／假標籤、Tiles 重複／條件／模型作用域與 getter；WP4 AST／選擇器／動態值／回呼／呼叫來源／深度；WP5 URL 引擎缺 API、工作區 2.2 證據拒絕／隱私、契約／SERVER 缺漏、DTO 全候選／groups、schema 拒絕與歷史標示。細節見個別回報。WP5 schema 首次 [遠端失敗](https://github.com/sprangdes/screentrace/actions/runs/37091763857) 為新靜態測試 JavaParser 未自設 Java 17，保留斷言補設定後最終 CI 全綠。混合行為衝突、暫時 API 重複與 Struts 2 拒絕圖家目錄洩漏均先由失敗測試證明再修正。

## 5. 與指示文件的差異及理由

只有需求方決定：OQ-002 URL 常值例外（v1.2）、OQ-003 script src 受限 context 定位（v1.3）、WP5 明確 API context、OQ-004 工作區來源與隱私、OQ-005 歷史 core API、OQ-006 待替換舊報表／測試保留（v1.4）。全部寫入指示與 ADR；未自行採用未決方案、未放寬既有斷言。core 保持 MARKUP／CLIENT／SERVER，框架名稱僅 adapter／evidence。

## 6. 開放問題與風險

OQ-001–006 均已處理，無未決 M2 問題。無 context 不假設，多候選全列；未知 EL／JS／動態方法／群組／Validator DI 保留 UNRESOLVED 與原文。無執行目標程式、啟動目標系統或連資料庫。

歷史 core 建構子待原測試遷移後移除，正式分析禁止使用；舊 ReportGenerator／測試於 WP7、ReviewResultGenerator／測試於 WP8 隨舊碼移除，列入 ROADMAP 與工作包驗收。新檢視器注入／md 匯出及新共用模組只能接受嚴格 2.2。兩份 2.1 的合併只保留明確標示的歷史 2.1，混合版本拒絕，不靜默升版。

Windows launcher 與人工 report-design 未在本環境執行；WP7 的新單檔 HTML／CSP／互動驗收未開始，不能將既有 capture 安全測試視為 WP7 已完成。
