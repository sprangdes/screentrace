### 舊版失敗測試與既有測試更新

## WP42：名稱與說明更好懂

在檢視器中以單一純函式推導呈現名稱，優先採用可見文字、ARIA 標籤、標題、圖片替代文字、控制項值與表單標題；仍無可讀名稱時使用人性化屬性名或靜態 DOM 位置。已知導向目的會附在名稱後，同一畫面中的相同名稱才加序號。圖中的元件名稱、證據及 md 輸出維持原值。信心、決策與 API 狀態用語集中在 `terms.ts`；只有圖示的按鈕均由 DOM 測試檢查可存取名稱。

左側畫面清單的「保留／移除／未確認」按鈕預設隱藏，滑過、鍵盤焦點或觸控長按後才出現；已決定的畫面仍顯示狀態圖示。單擊與既有鍵盤操作均維持一鍵標記並寫入相同的畫面決策。

### 測試先行與顯示斷言

WP42 的名稱優先序單元測試、合成畫面 E2E 與側欄決策 E2E 先於實作加入。在 detached WP41 基線上重跑新測試：名稱優先序測試首個差異為舊版輸出 `表單 1`、預期 `Brand`；用語 lint 找到 `button-table.ts`、`details.ts`、`main.ts`、`simulation-ui.ts` 中散落的舊變體；側欄測試實測決策控制 `opacity` 為 `1`、預期 `0`。新測試分別鎖定名稱、可存取名稱、控制預設隱藏、滑過／鍵盤焦點／觸控長按顯示及一鍵標記。

僅更新本輪顯示文字或顯示狀態的斷言，逐處列於 [ADR 0065](../adr/0065-r12-wp42-readable-names.md)，並說明舊預期、新預期、原因與舊行為失敗點。決策鍵、保存格式、API 推導、證據、模擬、安全與 md 往返斷言未修改。
