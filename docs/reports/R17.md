# R17：回到主要流程，全面簡化

## 第一階段（WP60＋WP61，並提前完成 WP64）

### 結果

- 報表只剩「畫面」「API」兩頁。頂部列：頁籤、確認進度（點開可看保留／移除／未確認數量與衝突）、暫存狀態、下載 md、開啟 md、說明（?）。
- 左側欄：一個搜尋框（實際 URL 或畫面名稱，沿用路由樣板比對）、清單／檔案結構切換、狀態篩選（全部／未確認／保留／移除）。
- 中間：未選畫面時是畫布（保留原排版，移除泳道）；選了畫面是完整預覽，可點按鈕模擬操作。
- 右側欄：畫面名稱與網址、三段式決定（保留／移除／未確認）、衝突與 JSF 提示、按鈕清單（預設收合，頁首頁尾按鈕另成一組）、呼叫的 API、從哪些畫面可來到這裡。
- API 頁：一張清單，狀態只有使用中／未被使用／可移除；點一筆展開呼叫來源，點來源回到畫面並標出該按鈕。
- 快捷鍵：k／x／u 標記、n 下一個未確認、/ 搜尋、Esc 返回畫布、Alt＋←／→ 預覽歷史。
- §2 移除清單全部移除，被刪的模組與測試見 [ADR 0084](../adr/0084-r17-two-page-report-and-retired-tests.md)。
