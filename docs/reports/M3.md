## 6. 開放問題與風險

無新增未決需求，OQ-001–006 仍已處理。重建不保證動態資料／條件與真實執行一致，明確標示示意及所有分支。無目標 Java／JSP／JS 執行、DB 或目標網路請求。

安全來源／資源上限及 Java 32 MiB 預覽檔讀取上限沿用；硬限制明確失敗，不靜默截斷。截圖尺寸超限時可能裁切圖片，但完整元素／樣式保留並標記；容量軟上限只警告、不刪資料。不同平台字型／Chromium 環境可能改變 rendering，決定性測試在同環境重複驗證。

舊檢視器在雙擊引發重繪時有選取狀態競態；標準「單擊選取→Page view」驗證通過。依 v1.4，WP7 隨舊檢視器移除，不遷移舊測試或擴大本輪重構。WP7／WP8 等下一輪，不以本輪驗收代替。
