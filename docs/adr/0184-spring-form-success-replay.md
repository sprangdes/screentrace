# ADR 0184 Spring 表單成功路徑回放

## 背景

同一個 POST 的正常送出與重送可能轉到同一畫面。報表逐一列出回傳分支時，使用者會看到重複目的地，並需要在尚未發生的例外分支中選擇。

## 決定

- 同一表單回放結果若目標及呈現內容相同，合併回傳證據。Application Graph 保留每個回傳位置。
- 當 Spring POST 的直接轉址分支同一區塊有字面 `RedirectAttributes.addFlashAttribute("success", ...)`，且報表可辨識唯一的成功目的，預覽直接回放該目的並顯示來源成功訊息。伺服器例外、重送、工作階段失效等關係仍可在分析圖追溯。
- 此類回放若有未勾選且可操作的必填核取方塊，停留在當頁提示。適用於此有來源證據的成功回放，擴充 ADR 0085 的表單行為。
- 帶有 `formaction` 或 `formmethod` 的提交按鈕使用自己的圖行為，例如確認頁的「返回修改資料」使用編輯端點。
- 報表依然是離線模擬。來源無法區分正常路徑時維持候選選擇。
