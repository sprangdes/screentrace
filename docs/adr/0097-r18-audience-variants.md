# ADR 0097：R18 身分畫面變體與保守外框投影

## 背景與選項

同一網址的頂層回傳若選擇不同畫面元件，合併顯示會讓需求方標記錯誤內容。選擇以來源條件拆分；局部控制項與未知狀態不拆分。

## 決定

- 以網址、來源檔與排序條件原子建立變體 ID；單一畫面沿用原 screenId。所有變體共用 ENTRY_POINT（path 為網址），以 INFERRED RENDERS 關係連到畫面。
- 頂層只回傳 Navigate 的身分分支記為入口的 NAVIGATE 行為，不增加該分支的畫面。原有 redirectOnly forwarding address 相容行為保留完整候選集合。
- 以同一 audience 矛盾規則投影元件、行為與靜態預覽。無法證明的自由變數保留；被排除的完整元件／行為及來源保存在畫面 attributes 的 hiddenComponents／hiddenBehaviors，標示「此身分下不顯示」與條件依據。
- 共用元件在不同畫面投影完全相同時，沿用既有共用 ID 與單一行為；只有 guard／效果投影不同時，以不含行號的投影鍵分出穩定 ID，避免行為跨身分洩漏。決策仍採原 screenId 與 (screenId, componentId) 複合鍵。
- 有變體的圖使用按網址分組的決定性格狀配置，同網址變體並排；無變體的既有圖配置不變。URL 搜尋與 API caller 分組沿用共同索引，保留全部變體。
- 名稱附來源分支條件摘要（R18-C 待確認），不猜中文角色名。
