# ADR 0111：R20 報表呈現角色流程

## 背景

R19 已在 Application Graph 中保存每個角色的畫面判定與流程，但報表沒有任何呈現，使用者看不到不同角色的流程。

## 選項

1. 在 viewer 重新計算角色判定：與分析結果可能不一致，拒絕。
2. viewer 只讀圖中的角色資料，以清單、畫布標示與比較表呈現：採用。

## 決定

- R20-1：只有 schema 2.4 且 `application.personas` 為陣列時才讀取角色；格式不符的角色略過，報表照常開啟。沒有角色時不顯示角色選單、角色分頁或任何標示。
- R20-2：畫面狀態依流程分為確定可達（`reached` 中為 REACHABLE）、可能可達（POSSIBLE）、不適用（`screens` 中為 EXCLUDED）與未到達（其餘）。
- R20-3：總覽線依流程中兩端都是畫面的步驟標示；同一對畫面有任一 APPLIES 步驟即為確定，否則為可能；其餘線淡化。經由網址入口的步驟不畫成線，只反映在步數。
- R20-4：選取的角色只存在目前頁面，不寫入瀏覽器暫存、md 或進度檔；保留／移除標記與 md 內容不受角色影響。

## 後果

角色流程可在報表中逐步檢視與比較；可能可達的比例取決於分析能判定的條件，改善判定屬於後續工作。
