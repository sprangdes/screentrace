# ADR 0107：R19 角色設定、身分維度與 schema 2.4

## 背景

分析者需要以可追溯的條件定義角色，並查看來源中實際出現的身分維度。

## 選項

1. 從程式碼猜測角色名稱：無法確定，拒絕。
2. 從工作區設定讀取角色，使用現有 audience 原子規則：採用。

## 決定

- R19-1：角色名稱與條件只由工作區設定按專案路徑提供。
- R19-2：條件沿用 `atoms()` 與既有矛盾規則，不新增規則。
- R19-4：僅 React 畫面支援角色；其他專案提示並略過。
- R19-5：未設定角色時保持原圖位元組與 schema。
- R19-6：已設定角色的 React 圖採 schema 2.4，輸出身分維度及角色定義。

## 後果

條件可追溯至工作區設定的保留來源；矛盾角色略過，未匹配條件產生診斷。設定順序維持不變。
