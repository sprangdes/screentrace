# ADR 0110：R19 身分維度比對與外框重導

## 背景

身分維度超過 64 個時，截斷清單可能排除角色條件所用維度，造成假的 `PERSONA_FACT_UNMATCHED`。包在 `<Routes>` 外的 Guard 重導未成為入口重導，使角色流程無法走到實際目的畫面。

## 選項

1. 繼續以截斷清單比對並忽略外框重導：無法反映來源條件。
2. 以完整維度清單比對，並依固定路由判定外框重導：採用。

## 決定

- R19-11：角色條件使用完整維度清單比對，只有輸出的維度截斷為 64 個。
- R19-12：依引用維度的畫面數由多到少選取，次序相同依文字排序；輸出仍依文字排序。
- R19-13：外框重導的條件在產生時依固定路由求值，條件不矛盾時成為該路由的入口重導。
- R19-14：外框重導及畫面 load 中相同重導的角色判定使用固定路由求值結果。
- R19-15：未設定角色的 React 圖只新增入口 NAVIGATE 行為，節點、關係與 schema 不變；非 React 專案位元組不變。

## 後果

未設定角色時 React 專案的圖會新增外框重導行為（reservio +63），非 React 不變。
