# ADR 0055 — 元件配對與模擬覆蓋率原因分離

狀態：採用（OQ-018，2026-10-05）。

元件未對應的預覽欄位 unmappedReason 維持五個列舉，只有可操作且未唯一對應的元素使用。已唯一對應卻無法模擬的元素不寫入此欄位。viewer 使用模擬層共用的元件行為集合、事件適用判定、證據狀態、simulate 與 canSimulate；覆蓋率和點選說明不得重作另一套可模擬規則。

需求方只看到中文兩層分類：沒有已知的行為（可能由頁面腳本控制）；已記錄行為但無法確認結果，其子類為行為有歧義、目的未解析、行為類型不支援模擬。原生可輸入欄位排除於無法確認分類之外。單元素覆蓋率沿用原事件判斷，送出按鈕的 submit 事件不能因此變成 click；實際表單送出仍沿用原表單處理。

先提交自行撰寫的 petclinic 風格向量與失敗測試。舊實作缺少 assessSimulation、unmappedReason，且契約沒有欄位驗證，因此新增三個測試全部失敗（/private/tmp/wp29-red.log）。另新增畫面及全專案不變量、四種合成 family 與中文離線點選 E2E。

不修改任何既有斷言、fixture、golden、圖 schema、元件 ID、行為信心、API／review／md 規則；無既有斷言需授權調整。真實專案僅唯讀分析，資料／輸出不提交。
