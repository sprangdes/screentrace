# ADR 0085：R17 畫布 zoom in 聚焦與點擊模擬

## 背景

R17 WP62：需求方要求點畫布上的畫面時，在同一張畫布上 zoom in 到該畫面，四周只留下它出發的關聯線，線的方向就是原畫布上的方向；滑過線顯示目的畫面縮圖，點線前往。原本的做法是另開「聚焦板」，把目的畫面重新排在四周（`focusLayout`），與原畫布沒有關係。

R17 WP63：模擬操作改為「點了會怎樣就怎樣」，表單不做資料檢核攔截。

## 決定

### 聚焦（`canvas.ts`）

1. 畫布回傳 `CanvasView`（`focus`／`exit`／`update`），整個「畫面」頁只建立一次；搜尋、篩選、標記只更新卡片狀態與可見性，不重建畫布，因此聚焦中的狀態不會被打斷。
2. `focus(id)`：記下目前的畫布平移縮放，其他卡片與總覽線淡出，`world` 以 400 ms 轉換平移縮放，使卡片 A 填滿中央的聚焦框（四周留 96 px、上方 40 px 給線）。轉換結束後在聚焦框中放入完整預覽（沿用 `prototypeViewer`），並畫出線。`prefers-reduced-motion` 時直接切換。
3. 線的集合＝總覽畫布上 `from=A` 的線（`partitionNavigation().flows`），加上目的無法確定的出口（`focusedRelations` 的 unresolved，每個觸發元件一條）。方向取兩張卡片中心在原畫布上的連線；同一方向 5° 內的多條線以 18 px 平行錯開，角度不變。自我循環畫成框右側的回圈；無法確定的出口是框下方的短虛線，不可前往。
4. 滑過（或鍵盤聚焦）線：顯示 `relationTooltip`（名稱、URL、縮圖、觸發按鈕），並在預覽中以藍框標出觸發按鈕。點擊（或 Enter）前往目的畫面＝對目的畫面再呼叫一次 `focus`。
5. `exit()`：還原進入聚焦前的平移縮放（同樣有轉換），恢復所有卡片與線。Esc、「返回畫布」、在線區滾輪向下都會退出。
6. 歷史沿用 `PrototypeHistory`（Alt＋←／→、工具列上一頁／下一頁），不寫入網址。

舊的聚焦板（`focusLayout`、`focusBoardHeight`）刪除。

### 點擊模擬（`simulation-ui.ts`）

1. `simulate()` 的計算不變，候選集合與目的畫面與既有 fixture 完全相同。
2. 表單一律以「有效」送出：不呼叫 `checkValidity`／`reportValidity`，不顯示伺服器檢核訊息。
3. 唯一目的畫面直接聚焦過去；多個候選在點擊位置下方列出（縮圖＋名稱），選一個前往；彈窗照舊顯示；呼叫 API 顯示一行「呼叫 API：…（不會真的送出）」並可切到 API 頁；目的無法確定時顯示「無法確定前往哪個畫面」。
4. 移除覆蓋率統計、技術證據展開、Alt 點擊只選取、觸控長按、首次脈動外框。可模擬的元素滑過時有外框與手指游標。

## 測試

新增 `r17-focus.e2e`：聚焦後只剩 A；聚焦線集合＝總覽線集合；每條線與原畫布中心連線角度差 ≤ 15°；無法確定的出口數＝觸發數；滑過顯示縮圖並標出觸發按鈕；Enter 前往；Esc 還原平移縮放；`n` 前往下一個未確認；有動畫時預覽在轉換後才出現；連結直接前往、空白必填欄位的表單送出不被攔截並列出候選。

調整既有測試（只改定位與文字，不改模擬結果）：`wp26-simulation.e2e` 移除「原生檢核」「請確認姓名」的預期（WP63 明確移除檢核攔截），未知結果文字改為「無法確定前往哪個畫面」，列出候選後以 Esc 關閉；`wp25-prototype.e2e` 改比較畫布 `transform` 值（聚焦退出時樣式含轉換屬性）；`r17-shell.e2e`、`review.e2e` 以 `:not([hidden])` 計算可見卡片（篩選改為隱藏卡片而不是重建）。

另外：刪除 `relations.test` 中鎖定舊聚焦板 `focusLayout` 的測試（函式已退場）；`guide-screenshot-stability.e2e` 等待「預覽載入中」的前置步驟改用 10 ms 間隔輪詢，因為聚焦後預覽的載入中狀態只維持約 240 ms，Playwright 以畫面更新為準的輪詢會錯過；測試要驗證的截圖就緒條件不變。
