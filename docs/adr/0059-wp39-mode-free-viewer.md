# ADR 0059：WP39 的無模式畫面檢視器

## 狀態

已採納。

## 決定

WP39 移除完整畫面檢視器的操作／檢查切換、可操作元素顯示勾選與縮放下拉；點擊一律沿用原有模擬入口，Alt／Option 點擊只選取，觸控長按只選取。樣式固定放在右側「樣式」分頁，操作、API、檢核與技術細節仍可到達。「流程視圖」改名為「看流程」；重置、回到起點與縮放比例收在鍵盤可操作的「⋯」選單。沒有變更分析結果、模擬推導、圖 schema、review 狀態或 md 契約。WP40 與 R10 WP37／WP38 未開始。

## 被授權調整的既有測試預期

| 測試 | 舊預期 | 新預期 | 原因 |
|---|---|---|---|
| `details.e2e.mjs`：focus links / ordinary preview styles | 流程按鈕名為「流程視圖」；樣式直接出現在一般元素資訊欄 | 按鈕名為「看流程」；五個固定分頁中由「樣式」顯示同一組樣式值，來源證據在「技術細節」 | WP39 改名並將樣式移到固定分頁；顏色、字型、來源檔與行號仍檢查。 |
| `r4-canvas.e2e.mjs`：UI2、focused preview | 流程入口名稱為「流程視圖」 | 名稱為「看流程」；畫布邊界、流程線、review 操作斷言保留 | 只更新可見控制項名稱。 |
| `r4-details.e2e.mjs`：UI3 tabs | 右欄四個分頁 | 五個分頁，樣式使用固定「樣式」分頁；API、檢核、證據及匯出斷言保留 | 新增固定樣式分頁。 |
| `r5-endpoints.e2e.mjs`、`wp16.e2e.mjs`、`wp18.e2e.mjs`、`wp20.e2e.mjs` | 流程入口可存取名稱為「流程視圖」 | 改為「看流程」；各測試原有流程／候選／診斷內容斷言保留 | 控制項更名。 |
| `wp25-prototype.e2e.mjs` | hover 樣式 selector 為舊 `.preview-hover`；重置為工具列常駐按鈕 | 使用 `.st-preview-hover`；重置位於「⋯」選單；導覽、樣式、歷史與離線斷言保留 | WP39 統一預覽 hover 樣式並移動重置入口。 |
| `wp26-feedback.e2e.mjs`、`wp26-simulation.e2e.mjs` | 先切換操作／檢查模式，再點擊；樣式與操作共用一般右欄 | 點擊直接模擬；樣式改由「樣式」分頁檢視；同一候選、檢核、API、離線與 md 位元組斷言保留 | 模式切換移除，模擬結果不變。重置改由「⋯」選單進入。 |
| `wp39-simplify.e2e.mjs`（新增） | 舊介面仍有操作／檢查按鈕（舊版實測找到 2 個） | 不存在模式控制項／縮放下拉；檢查「看流程」、選單、分頁、Alt 選取、點擊模擬、觸控、離線與探針 | 新規格的直接驗收。 |

新增測試先於實作提交於 `bdc60b0`。在該 commit 的舊實作快照執行 `npm run build && node --test test/wp39-simplify.e2e.mjs`，測試 1 項、通過 0、失敗 1；第一個預期差異為舊工具列仍有 2 個被禁止的控制項，實際 2、預期 0。相同快照執行 `node --test test/wp35-feature-regions.e2e.mjs`，JSP 根目錄測試 1 項失敗；「首頁與其他」區域實際包含乙頁，預期應包含無 JSP 子目錄的甲頁。新實作的前端完整 E2E 通過，見 [R11 報告](../reports/R11.md)。

## 結果

檢視器不再要求使用者先切換操作／檢查模式；操作結果仍由同一模擬函式提供。樣式可固定從右側分頁查看，所有專案資料仍由 textContent 呈現，預覽維持無 script sandbox 與離線 CSP。功能區域的 JSP 根目錄歸入「首頁與其他」，找不到 JSP 來源的畫面清楚標示「無對應 JSP 檔」，詳見 ADR 0058 與 R11 報告。
