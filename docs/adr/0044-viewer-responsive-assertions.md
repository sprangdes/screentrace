# ADR 0044：R4 UI5 響應式與實際鍵盤驗證

## 背景與授權

R4 §4.6 指定 1024–1279px 的右側覆蓋抽屜、<1024px 的左側圖示收合及底部資訊抽屜。需求方另要求聚焦自動適合、API 專屬脈絡、載入占位、以 Playwright `keyboard.press` 驗證快捷鍵。只改 viewer，canonical graph、md、review 與 API 規則不變。

## 決定

- 總覽維持決定性格狀。相鄰卡片走最近端口；跨列流程由來源欄走廊繞至目的上／下端口；自迴圈只繞一次，不回描同一段。不同方向的真實流程保留各自箭頭，不能為視覺整齊刪除關聯。走廊間距由 2–3px 改為 12px，避免緊鄰線呈現重影；既有全畫面對的不穿越卡片測試保持原斷言。
- 聚焦以固定邏輯座標建立圖，依主區可用寬高縮放並置中；ResizeObserver 重算，不使用水平捲軸。<1280px 聚焦預設關閉資訊抽屜，頂列「查看資訊」可開啟；API 主動選取則打開詳情。Esc 先關資訊，再返回上一畫面。原生分析資訊 dialog 用真實 Esc 關閉，焦點返回開啟按鈕。
- API 模式完全隱藏畫面左欄；`/` 聚焦 API 搜尋，右欄空狀態依模式變更。
- srcdoc 載入前顯示縮圖／骨架與狀態文字；load 後才顯示 iframe。sandbox 仍不允許腳本。減少動態效果設定停用骨架動效。
- Tab 按 DOM 順序走訪可見、啟用控制項；不新增正值 tabindex，不以合成 keydown 取代真實鍵盤。

## 授權變更逐處記錄

| 測試 | 舊預期 | 新預期 | 原因 |
|---|---|---|---|
| diagnostics.e2e.mjs：narrow 800px layout（改名以描述新布局） | nav ≥190、main ≥500、aside ≥780，aside 位於 main 下方 | nav=56、main≥700、aside≥780；預設隱藏，開啟後為 fixed 底部抽屜且覆蓋主區下半部 | 舊斷言鎖定被取代的堆疊布局；R4 §4.6 要求圖示收合與底部抽屜。保留 aside 寬度斷言，新增固定定位／預設隱藏斷言。 |
| r4-shell.e2e.mjs：UI1 shell has no document overflow（互動前置，未更動斷言） | 窄屏直接點左側畫面列 | <1024px 先點「展開畫面清單」，再點同一列 | 新預設收合使列不可見；所有寬度、三模式的原水平溢出斷言保持。 |

其他既有斷言、fixture、golden、證據與安全測試均未變更。新測試保留舊 UI4 產物另外執行，結果見 R4.md。沒有修改 analyzer 或 graph schema。

## 後果與限制

窄屏縮放使縮圖與卡片文字較小；可在資訊抽屜讀完整資訊。開啟抽屜會暫時覆蓋畫布一部分，關閉後恢復完整圖。格狀布局尚未改成流程分層；不同真實流程仍可能共用走廊，hover 可分辨來源與目的。

OQ-015 已決定採 A：無確切 tag-body 對應者暫用圖中 title；UI3 此項未完成，另案處理，記入 ROADMAP，不猜配。
