# ADR 0071：R14 WP48–WP49 UI 斷言遷移

## 狀態

已接受。

## 背景

R14 §2.4 授權修改直接鎖定舊按鈕合併規則、匯出前檢查對話框及其測試流程的斷言。WP48 將「只合併全站導覽」替換為依顯示名稱與行為簽章分組；WP49 以交付清單頁替換匯出前檢查對話框。其他資料、安全、決策鍵、Markdown 往返與模擬斷言均保留。

## 決定

以上修改限於 R14 §2.4 授權的按鈕合併、交付頁與其新 IA。除明列的新狀態用語、泳道排列及指南截圖資產外，其餘測試變動只調整進入頁面、打開收合區或鎖定正確可見列；完整成員、差異行為、不可標記狀態、Markdown bytes、決策原因與備註、下載名稱、匯入回饋、人性化名稱、資料正確性、安全與決策等價斷言均保留。
