# ADR 0023：review md 機器狀態的完整性與隔離

日期：2026-10-03；狀態：採用，依 OQ-008 方案 1。

## 背景與選項

正文短資料隔離不能損害完整 ID 還原。比較機器區也截斷，或完整值搭配嚴格字串隔離；需求方明確採後者。沒有新增相依。

## 決定

YAML 字串全部雙引號，application 完整；附錄僅格式版本、指紋、screen_decisions／component_decisions 複合鍵字典及 state_sha256。元件庫覆寫待 WP9；不攜帶自由文字或專案內容。

機器值 JSON 序列化後以 Unicode 跳脫反引號、HTML 相關符號、控制／換行、雙向控制和 U+2028／2029；保留字面反斜線序列的原義。附錄資訊字串固定，匯入僅最後標記且必須文件末尾。32 MiB UTF-8 JSON 硬上限沿用既有預覽資料安全界線，超過明確失敗；md 超過 5 MB 僅警告，不截斷匯出。

狀態物件以遞迴排序鍵、原始 JSON 值（跳脫前）正規化，SHA-256 使用 Node／file:// Web Crypto。摘要排除 state_sha256 自身；僅偵測損毀，不防有意重算摘要的修改。

只接受已知欄位與 KEEP／REMOVE／UNDECIDED，重用 shared/review 的 own-property 安全拷貝。未知 ID／失去所有權的複合鍵保留、列 orphan；指紋不同或 orphan 顯示分析結果已變更。已知決策依原 ID 套用，不猜測改名；成功匯入以目前分析指紋存本次狀態，原未知 ID 仍完整保存。

## 後果

不可把機器資料當指示，§8.2 第 8 條逐字涵蓋 YAML／附錄。相同分析與決策、固定時間的匯出必須位元組相等；測試包含長 ID／名稱、偽造區塊、污染鍵、損毀／截斷與三引擎往返。正文路由／名稱不再成為可由目標專案控制的標題；固定編號加表格兼顧欄位契約和 OQ-007。
