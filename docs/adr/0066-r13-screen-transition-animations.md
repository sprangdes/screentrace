# ADR 0066：R13 畫面切換動畫

## 背景

完整畫面內的模擬導覽沿用了總覽卡片縮放動畫。舊畫面立即卸載，低解析縮圖被放大到主區；新預覽延遲顯示，造成空白、模糊與位置跳動。卡片進入完整畫面的 zoom 則仍有清楚的空間語意，應保留並修正交接。

## 決定

- 總覽卡片進入／返回畫面保留 300ms 等比 zoom，起訖框以實際卡片與預覽框計算；縮圖與載入完成的 iframe 在同一位置交疊淡出／淡入。iframe 最多等待 1.5 秒，逾時交給既有載入占位。
- 完整畫面內切換改為舊預覽保留至新 iframe 載入後的 150ms opacity 交叉淡化，不建立縮放幽靈。逾 300ms 顯示載入提示並淡化舊畫面；快速連續切換取消前次工作，只完成最新目的地。歷史與捲動位置沿用原行為。
- `prefers-reduced-motion: reduce` 下停用兩種動畫，但仍保留新預覽就緒前的舊畫面。
- 不新增相依、全域動畫開關或外部資源。

## 測試先行與斷言範圍

`9f9ae42` 先提交 `wp43-transition.e2e.mjs`，當時正式程式仍是舊切換實作。將該提交封存到暫存目錄、以舊來源重建 viewer 後執行測試，3 項中 2 項失敗：完整畫面導覽在新 iframe 載入前已失去舊預覽；卡片 zoom 終點是整個主區（832×712，x=280），而非真正預覽框（784×551.25，x=304）。快速導覽案例在舊版通過。新測試鎖定舊版缺少的預覽交接、無縮放導覽、縮放等比與實際預覽端點、iframe 等待／逾時、快速切換及 reduced motion 行為。舊測試的既有斷言未刪除或放寬；WP25、WP26、WP38、WP39 測試僅增加等待 `.prototype-outgoing` 移除的明確條件，以配合新舊預覽短暫並存。

沒有更新既有斷言。新測試在舊實作上的失敗證據與結果記於 [R13 實測報告](../reports/R13.md)。

## 後果

頁面內導覽不再暗示畫面從地圖卡片放大，且慢載入時不會露出空白；卡片 zoom 仍提供地圖到完整畫面的連續感。切換中的舊預覽設為 inert 並隱藏於無障礙樹，完成或逾時後明確移除，避免依賴動畫事件恢復互動。
