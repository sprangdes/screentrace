# ADR 0116：R25 網址參數由連結決定，不算角色條件

## 背景

同一路由依網址參數（例如 `?lineLogin=success|failed`）分成兩個畫面：不帶參數的版本與帶參數的版本（OQ-038）。不帶參數的版本記錄了「參數不是 success、也不是 failed」的條件。角色判定把這些條件當成角色要滿足的條件，但角色設定不會、也不該寫網址參數，所以 reservio 訪客的登入、註冊、忘記密碼都只能判為「可能走到」。其實帶不帶參數是由連進來的網址決定：首頁連到 `/login`，分析器也已經把這條導覽指到不帶參數的版本。

## 決定

- R25-1：判定角色是否適用不帶參數的版本時，不計「參數不是這些值」的條件；畫面本身仍保留這些條件。帶參數的版本不變，仍需要連結帶上參數。
- R25-2：導覽的網址沒有決定是哪個版本時（例如網址由變數組成，目標同時包含同一路由的兩個版本），這條導覽對角色最多是「無法判定」，兩個版本都不會因為它變成「會走到」。
- R25-3：判定用的參數條件只存在分析過程中，不寫入輸出的圖。

## 後果

reservio 訪客「會走到」由 1 個增加為 5 個（首頁、登入、建立客戶帳號、建立商家帳號、忘記密碼），5 個畫面由無法判定改為適用；顧客、商家、未開店商家不變。網址由變數組成的導覽（例如帶 `returnTo` 的登入網址）仍是無法判定，這是刻意保守的結果。
