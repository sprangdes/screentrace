# ADR 0114：R23 角色頁改用 API 頁的版面

## 背景

R22 的角色比較頁是橫跨整頁的大表，使用大圓標、大縮圖與多行欄位標題，報表其他頁都沒有這種寫法；其他頁一律是左側清單、右側內容（API 頁），或左側清單、右側畫布（畫面頁）。使用者認為 R22 的呈現與整個系統不搭。

## 選項

1. 比照 API 頁：左側角色清單、右側選取角色的內容：採用。
2. 同樣版面但以畫面為主（左側畫面、右側各角色狀態）：看單一角色走過哪些畫面不如選項 1 直接，不採用。
3. 拿掉角色分頁，改放進畫面詳情與清單篩選：沒有一處能看整體比較，不採用。

## 決定

- R23-1：角色頁沿用 API 頁的版面與元件（`api-page`、`api-master`、`api-list`、`api-row`、`api-detail`、`api-section`、`api-screen-link`、`api-caller`、`api-shared`），只為角色需要的部分加少量樣式。R22 的表格、圓標、縮圖與相關樣式移除。
- R23-2：左側每列是角色名稱、說明與「會走到 N · 可能走到 N」，可用上下鍵切換。開啟分頁時選取畫布上目前的角色，沒有時選上次看的角色，再沒有時選第一個。
- R23-3：右側依序為標題與「在畫布上看流程」按鈕、說明與數量、判定條件、起點、流程（依步數列出畫面連結與網址，可能走到加小標籤）、和其他角色比較（只有這個角色、與其他角色共用，預設收合）、流程以外（走不到、不適用，預設收合）。
- R23-4：點畫面以該角色開啟；該角色走不到的畫面會連同「走不到、不適用的畫面」一起顯示。

## 後果

角色頁與 API 頁的操作和外觀一致。所有角色並排的一張表不再提供，跨角色的比較改由每個角色的「和其他角色比較」呈現。
