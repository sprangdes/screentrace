# ADR 0035：聚焦畫面的四周 SVG 關聯

日期：2026-10-04。狀態：採用（R2 WP11）。

## 背景與選項

聚焦畫面只在預覽旁列出導頁按鈕，無法滿足需求原文要求的四周關聯線。可增加圖形套件，或用現有 DOM/SVG 呈現穩定位置、可鍵盤操作的連線與目的節點。

## 決定

保留既有 `indexGraph` 對同來源／目的畫面的合併結果；聚焦視圖以四側分配目的節點，SVG 同時繪製可見線與透明粗命中線。節點超過 12 個時畫布依側列向下延展並可捲動，每一節點均能到達。線、節點 hover／focus 共用含名稱、URL、縮圖狀態及所有觸發按鈕的提示。自我導向保留為迴圈；無目的畫面顯示明確空狀態。沒有靜態目標的導頁行為保留成虛線「未解析」節點，不能點擊到任意畫面。沒有新增相依或圖 schema。

## 後果與驗證

SVG hit path 支援滑鼠與 Enter／Space 鍵，目的節點是原生按鈕；返回歷史仍由既有聚焦流程處理。純函式測試檢查四側分布及 1／12／13／80 個目的不重疊；Chromium E2E 實際 hover 線、核對 URL／觸發元件與縮圖提示、點擊導頁與返回，並檢查無關聯／自我／未解析情境。
