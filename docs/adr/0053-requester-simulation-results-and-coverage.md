# ADR 0053：WP26 驗收後的摘要、送出結果與覆蓋率

依需求方本次明確指示，送出結果預設只顯示中文摘要、全部候選及每個候選一句可由既有圖／來源證明的白話原因。不推測新增／編輯用途，只說來源表單對應該路由、無法確認本次用途。條件未執行判斷。原英文證據、來源行號、候選值與運算式完整留在每個候選下方「技術細節」，預設收合。本次指示取代ADR0052模擬結果自動展開技術證據的呈現；原有圖／證據內容不改。既有behaviorDetail的OQ-011呈現不改。

結果區置於預覽上方，最大高度min(180px,25vh)、內部捲動；展開所有證據也不能無限向下推動預覽。不截斷候選、證據或SERVER訊息。容器改為div，避免段落容器嵌套區塊。

操作模式的元素摘要顯示標籤、類型、行為、目的畫面、可前往的API及中文信心。目的只依既有純圖規則，無法確認不猜。計算樣式與來源放在收合的技術細節；檢查模式保留原樣式優先顯示，舊流程視圖的元素檢查亦保留。選取與確認決策不變。

覆蓋率維持同一DOM母集合，但分成互斥三類：X為有圖支持的行為元素（每個元素計一次，多個行為不重複）；其餘可原生編輯的input/select/textarea為Y（排除hidden、submit/button/reset/image/file、disabled與readonly）；剩餘為無法確認Z。X+Y+Z=N。原生欄位不再因沒有腳本模擬而算未知；JS後续效果仍不宣稱可模擬。缺失文件畫面數另報。分類只改檢視器措辭，分析、schema、API推導與md不變。
