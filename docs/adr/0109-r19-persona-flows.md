# ADR 0109：R19 角色流程可達性

## 背景

畫面與導覽的角色判定需要組成可追溯的流程，並區分已證明與可能到達的畫面。

## 選項

1. 將未知視為成立：會誤稱可達，拒絕。
2. 以兩次廣度優先搜尋分別計算確定與可能路徑：採用。

## 決定

- R19-7：角色判定由 JS 計算，流程可達性由框架中立的 core 計算。
- R19-9：每個角色從自己的入口獨立走訪，不推導角色轉換。
- 入口展開畫面渲染及重導；畫面展開重導與所含元件導覽。排除的目的畫面改從其入口繼續重導；未判定導覽去重計數。第一次 BFS 只走 APPLIES，第二次走所有可用步驟，分別標為 REACHABLE 與 POSSIBLE；記錄最短深度、步驟及未到達畫面。

## 後果

未知條件保留為可能路徑，無法解析的起點產生診斷；角色轉換留待後續。
