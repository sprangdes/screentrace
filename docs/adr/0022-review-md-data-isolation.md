# ADR 0022：review md 的專案資料隔離（OQ-007）

日期：2026-10-03；狀態：採用。需求方已明確選擇方案 A。

## 背景與選項

md 需要條件與未解析目標等分析資料，完整禁止所有來源文字會失去需求；直接輸出原文則可能被後續 AI 誤當指示。OQ-007 比較允許經隔離的短運算式，或完全省略運算式；需求方限定採前者。

## 決定

允許標籤、路由／URL 樣板、guard、UNRESOLVED 目標與綁定選擇器、檢核欄位／訊息。不得輸出完整檔案、函式本體、完整敘述式、原始 HTML、base64 圖片及自由 evidence.detail。detail 僅接受解析器名稱、框架來源標籤、設定鍵、候選值、採用值白名單，不把任意片段猜測成白名單值。

專案衍生文字只放 code span；反引號圍欄長度超過內容的最長連續反引號。換行、控制與雙向控制碼用可見跳脫；表格分隔符跳脫。每段最多 300 字元，超長加需求方固定截斷標記與來源檔案／行號，不靜默截斷。正文不得生成專案控制的標題、清單或指示段落。

§8.2 加入需求方第 8 條固定警語。文件更新 v1.6，不改第 1／2 節。golden 與惡意 fixture 驗證反引號、換行、表格、雙向控制、script 標記、指示型句子、超長與自由 detail。

## 後果與待確認邊界

輸出不再攜帶自由 evidence.detail 或完整程式片段，來源行號仍供人類追查。Markdown 跳脫不代替 AI 對資料／指示的界線，固定警語不可省略。

機器讀取的 YAML／附錄 A 必須完整保存名稱與 ID，是否豁免 code span／300 字元尚無授權；見 OQ-008。未自行採用例外，WP8 實作依 §0.3 暫停；本 ADR 只記錄已確定的 OQ-007 決定。
