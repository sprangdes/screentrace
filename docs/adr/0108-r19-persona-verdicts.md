# ADR 0108：R19 畫面與導覽角色判定

## 背景

角色條件必須與畫面 audience 及導覽 guard 比對，並保守保留無法證明的情況。

## 選項

1. 猜測未知條件：拒絕。
2. 沿用現有 audience 矛盾及蘊含規則：採用。

## 決定

- R19-3：僅輸出可證明成立的 APPLIES、無法證明的 UNKNOWN、可證明矛盾的 EXCLUDED。
- R19-8：導覽判定只使用角色條件與元件及行為 guard，不併入所在畫面條件。
- 同一 behavior 的角色導覽結果重複時，相同狀態保留，不同狀態合併為 UNKNOWN；目的取排序後的聯集。

## 後果

共用元件的導覽判定不受所在畫面影響；畫面條件由流程走訪另行合併。
